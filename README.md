Netflix Customer Churn Analysis

Project Overview

This project analyzes Netflix customer subscription data using Microsoft Power BI to identify customer churn patterns and understand customer behaviour.

Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

Key Analysis

- Customer churn rate
- Subscription type analysis
- Customer engagement
- Average watch time
- Regional analysis
- Payment method analysis

Dashboard Features

- Interactive slicers
- KPI cards
- Charts and graphs
- Customer segmentation

Files Included

- Power BI dashboard (.pbix)
- Dataset
- Dashboard screenshots

Key Learnings

- Data cleaning and transformation
- DAX measures
- Data modelling
- Dashboard development
